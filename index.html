GOOD TO KNOW

A few quick
answers.

How do I install CineVault on Android?+
Tap Download APK to get the latest file from the official CineVault GitHub release. Open the downloaded APK on your Android device and follow the prompts. Android may ask you to allow installs from that source. Only enable this for sources you trust.
What version of Android do I need?+
CineVault currently supports Android 7.0 or newer.
Can I use CineVault on Android TV or a browser?+
Not yet. Android TV and web streaming are both coming soon — the Android mobile app is the only available build today.
Is CineVault open source?+
Yes. The CineVault Android app source is available on GitHub under the MIT License.
